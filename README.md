# Night Shift Tour

> In this haunted amusement park, one world's wall is the other world's door.
> You're the night-shift guide who can shift between day and night.
> Get your guests past the ghosts and demons to the Ferris wheel before your shift ends.

A top-down 2D pixel-art game made solo for **GitHub Game Off 2026** (theme: **SHIFT**).

- **Play in browser / download:** [<ITCH_PAGE_URL>](https://jonjud.itch.io/night-shift-tour)
- **Source:** this repository

## Controls

| Key | Action |
|-----|--------|
| WASD | Move |
| Shift | Swap world (day / night, 1.5 s cooldown) |
| R | Restart (on the end screen) |

## How to play

- Your guests follow you in a line. Lead them to the Ferris wheel to earn money.
- Pressing Shift swaps between the day world and the night world. A wall in one world can be a floor in the other.
- You can't swap if you or a guest would end up inside a wall (the screen flashes red).
- Moon gates (purple) are open only at night. Sun gates (yellow) are open only by day.
- Ghosts hunt your guests at night. Demons guard the carousel at night. Daytime is safe.
- Finish as many tours as you can before the shift timer runs out.

## Run from source

1. Install [Godot 4](https://godotengine.org/) (project made with 4.7, Compatibility renderer).
2. Open `project.godot`, press F5.

Export presets for Web and Windows are in `export_presets.cfg`.
